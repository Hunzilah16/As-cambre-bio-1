# CIE A Level Biology 9700 – Official Topical Marking Schemes

This directory contains official Cambridge Assessment International Education (CIE) format marking schemes for all Save My Exams topical question papers extracted from the `Topical 2026` archive.

## Official Cambridge Format Specifications

- **Cover Page (Portrait)**: Official Cambridge Assessment International Education examination header, subject code (9700), paper type, maximum mark, publication notice, and legal disclaimer.
- **Theory Papers (Landscape Page 2+)**: Official Cambridge Generic Marking Principles (Principles 1–6), Science-Specific Marking Principles (1–7), and standard abbreviations (`;`, `/`, `R`, `A`, `AW`, `<u>underline</u>`, `max`, `ecf`, `I`, `AVP`).
- **Marking Scheme Tables**: Standard 3-column Cambridge layout (`Question` | `Answer` | `Marks`) with 0.5 pt solid grid borders, point-by-point criteria ending in semicolons, essential terminology underlined, and inline examiner guidance notes.
