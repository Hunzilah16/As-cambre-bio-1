## 🔍 Mark Scheme Authenticity & Features

Every marking scheme is strictly aligned with Cambridge Assessment International Education (CAIE) standards:

1. **Exact Mark Allocation**: Explicit `[1 mark]` notation, intermediate credit, error carried forward (ECF), and alternative valid approaches (`OR`).
2. **Full Step-by-Step Solutions**: Complete mathematical derivations, formula substitutions, SI unit verifications, and vector / free-body diagrams.
3. **Examiner Guidance**: Key definitions, common student misconceptions, and tips from CIE senior examiners.
4. **Original Files Preserved**: All original raw downloaded files from the zip are kept intact in `_original_raw_downloads/`.
